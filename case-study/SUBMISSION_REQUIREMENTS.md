# 📦 Submission Requirements

## Branch

`submission/<github-username>/<selected-role>`

## Allowed location

`submissions/<github-username>/<submission-id>/`

## Required files

- `README.md`
- `report.pdf`

Optional:

- `analysis.ipynb`
- dashboard screenshots as `.png`

## README content

- participant name or GitHub username;
- selected role;
- submission title;
- tools used;
- report/dashboard link where applicable;
- declaration that no real employee data was added.

## Suggested PDF sections

1. Executive position
2. Evidence reviewed
3. Key findings
4. Competing explanations
5. Policy and governance review
6. Bangladesh legal/regulatory considerations
7. Data limitations
8. Recommendations
9. 90/180-day plan
10. Measurement framework
11. References

## File policy

Allowed: `.md`, `.pdf`, `.ipynb`, `.png`

Blocked: `.csv`, `.xlsx`, `.xls`, `.pbix`, `.zip`, `.7z`, `.exe`, `.bat`, `.ps1`, `.env`, `.pem`, `.key`

Limits:

- PDF: 15 MB
- Notebook: 5 MB
- Image: 3 MB each
- Total submission: 25 MB

## Restrictions

- Do not copy existing datasets.
- Do not modify official case, data, workflow, security or governance files.
- Do not commit secrets, tokens or real employee data.
- One pull request must contain one submission only.
- Existing project evidence remains the source of truth.
