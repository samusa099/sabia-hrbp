This case converts the existing Sabia HRBP analytics project into a **controlled, role-based business simulation**. All participants work from the same official evidence, but make decisions from different professional roles.

> **Final goal:** Prepare a management-ready position that distinguishes evidence, uncertainty and required action, and supports a defensible decision for Sabia Group.

## Case layers

| Layer | Purpose |
|---|---|
| Official case | Narrative, ambiguity, management questions and role briefs |
| Existing project evidence | Current synthetic datasets, processed files, workbooks, notebook and dashboards |
| Participant submissions | Restricted folder, PDF report, optional notebook and review feedback |

## Start here

1. Read `CASE_NARRATIVE.md`.
2. Review `MANAGEMENT_CONTEXT.md` and `EXECUTIVE_MANDATE.md`.
3. Select one role in `ROLE_TRACKS.md`.
4. Complete the external research requirement in `POLICY_AND_LEGAL_RESEARCH.md`.
5. Follow `SUBMISSION_REQUIREMENTS.md` and the repository submission workflow.
6. Use `RUBRIC.md` before opening a pull request.

## Evidence discipline

Every material claim must be classified as one of:

- **Verified evidence** — supported by the official project data or documents;
- **Management account** — attributed statement requiring corroboration;
- **Allegation** — unverified claim that must not be treated as fact;
- **External research requirement** — requires a current official source;
- **Evidence gap** — cannot be assessed without additional records.

## Effort

Expected effort: one focused analytical session to a full working day, depending on the selected role and submission depth.

## Responsible use

All records are synthetic. Do not add real employee data, credentials, confidential records or copied datasets to a submission.
